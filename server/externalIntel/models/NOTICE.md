# Model provenance

## eng.traineddata.gz

Tesseract "best" English trained-data model (LSTM), used for offline OCR
of uploaded external intelligence documents. No runtime network fetch is
required — loaded from disk. Source: `@tesseract.js-data/eng` npm package
v1.0.0 (`4.0.0_best_int/eng.traineddata.gz`), Apache-2.0 License,
https://github.com/naptha/tessdata.
